# V image identity anchor

Identity images are intentionally stored outside GitHub under `/root/.cyberboss/image-anchors/`.

HOME1 selects `v.jpg`, `harper.jpg`, both, or neither according to who appears in the requested scene.

Use a clear, front-facing, single-person portrait. PNG, JPEG, or WebP are supported; keep it under 20 MB. Because this is identity material, only commit the actual image when the repository is private and its collaborators are trusted.
